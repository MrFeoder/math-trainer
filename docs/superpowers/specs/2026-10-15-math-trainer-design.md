# Тренажёр «Квадраты и кубы» — дизайн

Дата: 2026-10-15
Статус: одобрен в чате, ожидает проверки spec

## 1. Цель

Статический сайт-тренажёр для заучивания квадратов и кубов чисел. Два **отдельных**
тренажёра: «Квадраты» и «Кубы». В каждом настраивается диапазон чисел («с какого по
какой») и тип ответа: **вписать число** или **выбрать из вариантов**.

Основной пользователь — школьник. Дополнительно предусмотрены профили для взрослого и
нейтральный (для учеников), которые меняют оформление и значения по умолчанию.

Сайт — новый, публикуется в новом репозитории `MrFeoder/math-trainer`. Существующий
проект `C:\Users\Фёдор\site` (репозиторий `MrFeoder/besplatniy-sait`) не изменяется.

## 2. Границы (scope)

Входит:
- Два тренажёра: квадраты и кубы, переключаются на одной странице.
- Диапазон «от … до …».
- Форматы задания: прямой, обратный, смешанный.
- Типы ответа: ввод числа, выбор из 4 вариантов.
- Раунд из N вопросов, экран итогов, разбор ошибок, лучший результат.
- Профили оформления с сохранением настроек.
- Публикация на GitHub Pages.

Не входит (YAGNI):
- Аккаунты, серверная часть, база данных.
- Таблица рекордов между пользователями.
- Другие действия (умножение, сложные выражения), корни, логарифмы.
- Напоминания, звуки, генерация картинок.

## 3. Технологии

- Чистые HTML + CSS + JavaScript, без сборки и без внешних зависимостей.
- Скрипты подключаются как **обычные** (не ES-модули), чтобы сайт открывался и по
  `file://`, и с GitHub Pages: ES-модули по `file://` браузер блокирует.
- `logic.js` оформляется в виде UMD-обёртки: в браузере создаёт глобальный объект `MT`,
  а в Node отдаётся через `module.exports` — это позволяет тестировать чистые функции
  без копирования кода.
- Тесты запускаются встроенным раннером Node (`node --test`); Node v24 присутствует,
  внешних пакетов не требуется.
- Хранение настроек и лучших результатов — `localStorage`.
- Целевые браузеры: современные Chrome/Firefox/Edge/Safari, включая мобильные.

## 4. Структура проекта


`index.html` подключает `styles.css`, затем `logic.js`, затем `app.js` — в этом порядке.
Никаких CDN и внешних шрифтов.

## 5. Экраны и интерфейс

Один экран, три состояния, переключаемые без перезагрузки страницы.

### 5.1 Шапка
- Заголовок «Тренажёр: квадраты и кубы».
- Переключатель тренажёра: кнопки-табы «Квадраты» / «Кубы». Активный таб определяет
  набор настроек и текущую сессию.

### 5.2 Панель настроек (для активного тренажёра)
- **Профиль**: «Школьник» (по умолчанию) / «Взрослый» / «Нейтральный».
  Профиль задаёт тему оформления и стартовые значения настроек. Смена профиля
  подставляет его значения в поля настроек (их можно тут же изменить вручную);
  дальше настройки из localStorage больше не перезаписываются профилем.
- **Диапазон**: числовые поля «от» и «до».
  - Значения по умолчанию: квадраты 1–20, кубы 1–10.
  - Допустимый ввод: целые числа от 1 до 100, «от» ≤ «до».
- **Формат задания**: «Прямой (`7² = ?`)» / «Обратный (`49 = ?²`)» / «Смешанный».
  По умолчанию — «Смешанный».
- **Тип ответа**: «Вписать» / «Выбрать из вариантов». По умолчанию — «Вписать».
- **Вопросов в раунде**: целое от 1 до 100, по умолчанию 10.
- Кнопка **«Начать»**. Заблокирована, пока настройки некорректны.

Настройки каждого тренажёра хранятся отдельно и восстанавливаются при следующем
открытии страницы. Профиль применяется только к выбору темы и к значениям по умолчанию
при первом запуске и при смене профиля.

### 5.3 Экран тренировки
- Прогресс: «Вопрос 3 из 10».
- Счётчики: верных ответов, ошибок; таймер от начала раунда (мм:сс).
- Крупная карточка вопроса.
- Режим «Вписать»: поле ввода (только цифры) + кнопка «Ответить»; Enter подтверждает.
  Поле автоматически получает фокус.
- Режим «Выбрать»: 4 кнопки-варианта в один столбец (на широком экране — 2×2).
- После ответа: карточка подсвечивается зелёным (верно) или красным (неверно), при
  ошибке показывается правильный ответ; поле и кнопки блокируются на время паузы
  (~0.9 с), затем автоматически показывается следующий вопрос.
- Кнопка «Прервать» возвращает в настройки (текущий результат не сохраняется).

### 5.4 Экран итогов
- «Верно X из N» и процент.
- Затраченное время.
- Разбор ошибок списком: `5²` → «вы: 20, верно: 25» (для обратного формата:
  `49 = ?²` → «вы: 6, верно: 7»).
- Лучший результат для текущих тренажёра/формата/типа ответа/диапазона.
- Кнопки «Ещё раз» (те же настройки, новый раунд) и «Изменить настройки».

## 6. Модель данных

```js
// Настройки одного тренажёра
{
  kind: "square" | "cube",
  profile: "kid" | "adult" | "neutral",
  from: 1,            // целое, 1..100
  to: 20,             // целое, from..100
  format: "direct" | "reverse" | "mixed",
  answerType: "input" | "choice",
  roundLength: 10      // целое, 1..100
}

// Вопрос
{ kind, n, format: "direct" | "reverse", prompt: string, answer: number }

// Результат раунда
{ kind, correct, total, seconds, mistakes: [{ prompt, given, answer }] }
```

Ключи `localStorage`:
- `mt.settings.square`, `mt.settings.cube` — настройки.
- `mt.best.<kind>.<format>.<answerType>.<from>-<to>` — лучший результат.
- `mt.profile` — выбранный профиль (для темы).

## 7. Логика (чистые функции)

Всё, что можно, выносится в чистые функции без обращения к DOM — их покрывают автотесты.

1. `validateSettings(settings) -> { ok, errors }`.
   Проверяет: целые числа, `1 ≤ from ≤ to ≤ 100`, `roundLength` целое `1..100`,
   формат и тип ответа входят в допустимые значения.
2. `buildPool(kind, from, to, format) -> Question[]`.
   Для «прямого»/«обратного» — по одному вопросу на каждое число диапазона; для
   «смешанного» — оба вида для каждого числа.
3. `shuffle(array)` — перемешивание (Fisher–Yates).
4. `nextQuestion(pool, used, lastQuestion)` — берёт следующий неиспользованный вопрос;
   если пул исчерпан, начинает пул заново, гарантируя, что вопрос не совпадает с
   последним заданным.
5. `makeChoices(question, count = 4) -> number[]` — верный ответ + 3 дистрактора,
   уникальные, неотрицательные, перемешаны. Набор дистракторов зависит от формата:
   - прямой вопрос (ответ `n²`/`n³`): типичные ошибки — `n·n ± n`, `(n±1)²`/`(n±1)³`,
     соседние значения;
   - обратный вопрос (ответ — основание `n`): соседние основания `n±1`, `n±2`, чтобы
     числа были правдоподобными.
   Если после отбора уникальных дистракторов не хватает, берутся соседние числа, пока
   не наберётся нужное количество.
6. `checkAnswer(question, given) -> boolean` — числовое сравнение; для режима выбора
   `given` — выбранный вариант.
7. `summarize(round) -> Result` — подсчёт верных, времени, разбора ошибок.

Формулировки вопросов:
- Прямой: `7² = ?` (для куба `3³ = ?`), ответ — число.
- Обратный: `49 = ?²` (для куба `125 = ?³`), ответ — основание.

## 8. Обработка ошибок и краевые случаи

- Диапазон: пустое поле, дробь, 0, отрицательное, «от» больше «до», значения больше
  100 — поле подсвечивается, рядом показывается текст ошибки на русском, кнопка
  «Начать» заблокирована.
- Диапазон от 50 до 100 — показывается предупреждение, что ответы большие (не блокирует).
- Диапазон `from == to` (например `20..20`) — тренажёр работает, вопросы повторяются.
- `roundLength` больше размера пула — пул переиспользуется без повторов подряд.
- В поле ввода разрешены только цифры; пустой ответ — мягкое сообщение «Введите ответ»,
  без засчитывания ошибки.
- Ввод с клавиатуры до появления вариантов не ломает состояние (обработчики
  игнорируют нажатия вне активной фазы ответа).
- Двойной быстрый клик по варианту не засчитывается дважды (блокировка после первого
  принятого ответа).
- Если `localStorage` недоступен или содержит мусор — используются значения по
  умолчанию, ошибок в консоли нет.
- Сравнение ответов числовое, поэтому `07` и `7` равнозначны.

## 9. Тестирование

Автотесты (`test/logic.test.js`, запуск `node --test`):
- `validateSettings`: корректные и все ошибочные варианты.
- `buildPool`: размер и состав для прямого/обратного/смешанного.
- `makeChoices`: 4 уникальных варианта, среди них ровно один правильный, все ≥ 0 —
  отдельно для прямых и обратных вопросов.
- `nextQuestion`: нет повторов подряд, пул переиспользуется.
- `summarize`: подсчёт верных/ошибок и списка ошибок.
- `checkAnswer`: `07` == `7`, неверный ответ — `false`.

Ручной чек-лист (обязательно прогнать перед публикацией):
- Оба тренажёра × все 3 формата × оба типа ответа — раунд проходит до итогов.
- Граничные диапазоны: `1..1`, `1..2`, `20..20`, `50..100`.
- Кривой ввод настроек: пусто, `0`, `-5`, `1.5`, `ab`, «от» > «до», `999`.
- Enter подтверждает ответ; повторные клики не дублируют засчёт.
- Перезагрузка страницы — настройки восстановились.
- Ширина экрана 360 px и 1440 px — верстка не ломается.
- Консоль браузера без ошибок и предупреждений.
- Страница работает при открытии файла напрямую (`file://`) и с GitHub Pages.

## 11. Критерии готовности

- Сайт опубликован по адресу `https://mrfeoder.github.io/math-trainer/`.
- Есть два отдельных тренажёра: «Квадраты» и «Кубы».
- Диапазон «с какого по какой» настраивается и работает.
- Есть оба типа ответа: вписать и выбрать из вариантов.
- Раунд из N вопросов завершается экраном итогов с разбором ошибок.
- Автотесты логики проходят, ручной чек-лист пройден, консоль чистая.
- Существующий сайт-конструктор не затронут.
