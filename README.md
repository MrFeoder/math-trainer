# Тренажёр «Квадраты и кубы»

Статический сайт-тренажёр устного счёта: два отдельных тренажёра — **квадраты** чисел и **кубы** чисел. Диапазон чисел настраивается (например, от 1 до 20), ответ можно **вписать** или **выбрать из вариантов**. Раунд состоит из заданного числа вопросов и заканчивается экраном итогов с разбором ошибок и лучшим результатом.

## Адрес сайта

https://mrfeoder.github.io/math-trainer/

## Как открыть локально

Скачайте папку с проектом и дважды кликните по `index.html`. Сайт работает по `file://` — сборка, сервер и установка зависимостей не нужны.

## Как прогнать тесты

Нужен Node.js 20 или новее.

```
node --test
```

Команда находит и запускает все файлы `test/*.test.js`:

- `test/logic.test.js` — чистая логика: валидация настроек, профили, генерация пула вопросов, варианты ответа, проверка ответа, итоги и лучший результат;
- `test/markup.test.js` — разметка: наличие всех нужных `id`, порядок подключения скриптов, темы оформления, отсутствие внешних ресурсов;
- `test/ui.test.js` — поведение интерфейса на минимальном DOM-стабе: раунд от старта до итогов, оба типа ответа, двойные нажатия, пустой ответ, мусор в `localStorage`, недоступный `localStorage`, смена профиля и тренажёра.

## Как устроен проект

| Файл | Роль |
| --- | --- |
| `index.html` | Разметка: шапка с табами, экран настроек, экран тренировки, экран итогов |
| `styles.css` | Оформление и адаптив; три темы — `theme-kid`, `theme-adult`, `theme-neutral` |
| `logic.js` | Чистая логика (`MT`): валидация, пул вопросов, варианты ответа, проверка ответа, итоги. Работает и в браузере, и в Node |
| `app.js` | Только DOM: состояние экранов, таймер, обработка ответов, `localStorage` |
| `test/` | Тесты (`node --test`) |
| `docs/superpowers/` | Дизайн-документ и план реализации |

Скрипты подключаются как обычные `<script>` (не ES-модули), поэтому страница открывается прямо с диска. Настройки и лучшие результаты хранятся в `localStorage` браузера по ключам `mt.settings.square`, `mt.settings.cube`, `mt.profile` и `mt.best.<вид>.<формат>.<тип ответа>.<от>-<до>`.

## Профили

- **Школьник** — квадраты 1–20, кубы 1–10 (по умолчанию);
- **Взрослый** — квадраты 1–30, кубы 1–15;
- **Нейтральный** — квадраты 1–20, кубы 1–12.

Профиль задаёт тему оформления и диапазон по умолчанию; после этого настройки можно менять вручную, и они сохраняются для каждого тренажёра отдельно.

## Проверка, что существующий сайт не затронут

Проект лежит в **отдельном** репозитории `MrFeoder/math-trainer` и никак не связан с репозиторием `MrFeoder/besplatniy-sait`. Ни один шаг этой работы не изменял файлы и настройки `besplatniy-sait`; чтобы убедиться, проверьте, что в `MrFeoder/besplatniy-sait` нет коммитов из этой работы:

```
gh repo view MrFeoder/besplatniy-sait --json name,pushedAt
```
